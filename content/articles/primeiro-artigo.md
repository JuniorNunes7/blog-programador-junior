# Um começo simples

Este blog publica artigos a partir de arquivos Markdown. O índice é gerado no deploy e cada artigo só é lido quando alguém escolhe abri-lo.

## Por que isso importa?

Menos dependências em tempo de execução deixam o servidor livre para entregar conteúdo com previsibilidade.
