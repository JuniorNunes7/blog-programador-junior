# Fontes de origem

Matrizes obtidas do repositório oficial [google/fonts](https://github.com/google/fonts): `ofl/manrope/Manrope[wght].ttf`, `ofl/sourcesans3/SourceSans3[wght].ttf` e `ofl/ibmplexmono/IBMPlexMono-Regular.ttf`. As respectivas licenças OFL são distribuídas junto das fontes públicas em `public/assets/fonts/`.

`bin/build-brand.py` gera instâncias estáticas WOFF2 com os pesos utilizados na interface e converte a marca em curvas. A direção tipográfica é definida exclusivamente em [BRAND.md](../../docs/design/BRAND.md).
